# Software FJ - Gestión de Clientes, Servicios y Reservas
Fase 4 - Programación (UNAD 213023). Sistema orientado a objetos en Python para gestionar clientes, servicios y reservas de Software FJ, con manejo de excepciones y registro de logs.
**Autor:** Jesús David Molina González

# Cómo ejecutarlo

1. Tener Python 3 instalado.
2. Descargar `proyecto.py`.
3. Ejecutar en la terminal: `python proyecto.py`

El programa simula 16 operaciones y guarda los eventos y errores en el archivo `software_fj.log`.
